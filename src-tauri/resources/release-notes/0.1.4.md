VoiceFlow shortcut editing uses a compact key label and a focused capture field with explicit actions. Capture is scoped to that field; Escape or leaving it cancels. Physical keys preserve Option/Shift combinations, and new bindings cannot intercept ordinary typing. Native capture operations are serialized across pages.
