# MIT attribution overlay

This additive attribution directory is included in VoiceFlow’s source tree. The existing `src-tauri/mlx-sidecar/scripts/package.sh` recursively copies `ThirdPartyLicenses/` into staged resources, and the `DependencyTexts/` verification walks this subtree. This integration has not been packaged or release-tested.

`standard/MIT.txt` is a byte-exact copy of the official SPDX MIT standard text saved with the audit. It remains a terms reference with the literal `<year> <copyright holders>` placeholder. It is not represented as a full body shipped by any of the six locked packages.

`package-credits.json` records each locked version’s declared MIT expression and package-author metadata with lock, archive, metadata, and source hashes. Author metadata is attribution metadata, not a copyright notice. The existing index still marks all six exact-release full-body records unresolved. The reviewed package archives contained no package-specific copyright notices.

`supplemental/` contains three exact upstream notice snapshots, separately classified in `supplemental-notices.json`. The `react-remove-scroll-bar` notice is from upstream version 2.3.7 while the lock is 2.3.8; applicability to 2.3.8 is unverified. The `malloc_buf` notice comes from a later upstream revision, after the 0.0.6 release tag; it was absent from that release tree. The RealFFT MIT notice was added by upstream's 3.5.1 missing-license repair. That commit changes Cargo.toml version, LICENSE, and README only; the Rust source is unchanged from locked 3.5.0. The notice is authentic supplemental evidence, not bytes in the 3.5.0 archive. The exact 3.5.0 row therefore remains `unresolved_no_full_text_candidate`. `provenance/realfft-later-upstream.json` records both revisions, changed paths, source/license hashes, and saved evidence references. None of these supplemental notices is legal clearance or evidence for another package.

The paired attribution notice has been appended to [`THIRD_PARTY_NOTICES.md`](../../../THIRD_PARTY_NOTICES.md). Preserve the six unresolved exact-release statuses in [`license-index.json`](../license-index.json) until exact-release evidence changes them. The `provenance/...` paths in `package-credits.json` refer to source-audit files maintained separately from this staged subtree. This overlay is attribution material, not legal clearance or a release-completeness finding.
