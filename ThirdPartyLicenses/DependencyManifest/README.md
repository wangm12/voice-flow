# Generated dependency identity files

`package.sh` copies the sidecar and Xcode `Package.resolved` files into this directory and writes `dependency-identities.txt` from those lockfile hashes, the local pinned `mlx-swift` checkout and its two nested MLX GitLinks, the selected Swift compatibility runtime file hash, and the pinned `mlx-audio-swift` source overlay identity. `mlx-audio-swift-source-overlay.json` records the exact upstream base, patch, four patched SDK files, and three hash-pinned Fun-ASR-Nano source files used by the Xcode build. Before building, the package step accepts either the exact pinned base or the one recorded predecessor overlay image: its three exact after-hashes must be the only unstaged checkout changes, the other declared SDK source must remain at base, and all added source paths must be absent. It applies the current overlay from pinned Git blobs and publishes only the missing files. Post-build checks accept only the complete current after-state with the exact declared dirty paths. The package step also fails if either lockfile changes during resolution/build or either nested MLX source checkout does not match the parent GitLink.
